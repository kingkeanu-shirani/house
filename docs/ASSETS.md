# Source and asset provenance

The original Python environment, catalog and build brief were supplied by the
user and are preserved byte-for-byte under `catalog/raw/`. No separate source
license was included with them. They are retained here as the user's project
inputs, without inventing a redistribution license.

The added implementation, tests and documents were created for this project.
There are no downloaded third-party models, images, meshes, sounds, datasets or
code snippets. Runtime imports use Python's standard library. Optional package
building uses the installed setuptools tooling; it is not bundled in this ZIP.
